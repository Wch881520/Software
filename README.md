# 本地健康记录

一个记录血压和睡眠的本地小程序，数据保存在当前目录的 `health_records.db`，不会上传网络。

## 启动

在当前目录执行：

```bash
python3 app.py
```

电脑打开 <http://127.0.0.1:8765>。

## 手机使用

1. 电脑启动程序后，终端会显示一个局域网地址，例如 `http://192.168.1.8:8765`。
2. 手机和电脑连接同一个 Wi‑Fi，在手机浏览器打开这个地址。
3. 在浏览器菜单中选择“添加到主屏幕”或“安装 App”，之后就可以像 App 一样打开。

如果手机无法访问，请检查电脑防火墙是否允许 Python 接受局域网连接。这个版本的数据仍然保存在电脑本地；手机只是通过局域网访问它。

## 导出记录

在页面底部对应记录右侧点击“导出 CSV”，即可下载全部血压或睡眠记录，用 Excel 或 WPS 打开。

按 `Ctrl+C` 停止程序。首次运行会自动创建 SQLite 数据库。
